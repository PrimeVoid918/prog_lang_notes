| **Term**       | **What it is in Go**     | **Think of it in JS / TS / Dart as...**               | **Short Explanation**                                                                                                                            |
| -------------- | ------------------------ | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Slice**      | `[]type`                 | `Array` or `List<T>`                                  | A dynamically-sized, resizable view of a sequence of elements.                                                                                   |
| **Map**        | `map[key]value`          | `Map` or a plain Object (`{}`)                        | A collection of key-value pairs (hash table).                                                                                                    |
| **Struct**     | `type Name struct`       | `Interface` (for objects) or a class with no methods. | A blueprint defining a blueprint/shape of custom data.                                                                                           |
| **Zero Value** | Default state            | `undefined` or `null`                                 | Go variables **never** start uninitialized. If empty, an `int` defaults to `0`, a `string` to `""`, a `bool` to `false`.                         |
| **Goroutine**  | `go myFunction()`        | `async` / Worker threads                              | A lightweight, independent thread managed by the Go runtime, not the OS.                                                                         |
| **Channel**    | `chan type`              | Streams / RxJS Observables                            | A pipe or conduit used to pass data safely between Goroutines.                                                                                   |
| **Panic**      | `panic("error")`         | `throw new Error()`                                   | A critical crash runtime error that stops the program execution immediately.                                                                     |
| **Recover**    | `recover()`              | `catch (e) {}`                                        | A built-in function that regains control of a panicking program.                                                                                 |
| **Receiver**   | `func (s *State) Move()` | `this` in a Class method                              | A special parameter attached to a function that turns it into a method for a Struct.                                                             |
| **Exported**   | Capitalized names        | `export` keyword                                      | Go has no `export` keyword. If a function or variable starts with a **Capital letter** (e.g., `Println`), it is public. Lowercase means private. |
